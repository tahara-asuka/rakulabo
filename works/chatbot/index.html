整体院を例に、予約の受付・料金の案内・よくある質問への応答を自動化したチャットボットです。右のウィンドウに、実際に話しかけてみてください。営業時間や料金を聞いても、そのまま「予約したい」と言っても構いません。

このページは制作サンプルです。「なごみ整体院」は実在しません。

何を自動で受けているか

店舗の問い合わせは、内容がほとんど決まっています。営業時間、料金、駐車場、初回の流れ、予約。これらは人が毎回答える必要がありません。手が離せない時間帯の取りこぼしを、まず無くすことが目的です。

  • 24時間受付。閉院後や施術中の問い合わせも取りこぼしません。
  • 9割店舗への問い合わせの多くは、営業時間・料金・予約の3つに集中します。
  • 0秒返答までの待ち時間。折り返しの電話が不要になります。

答えられないときは、無理に答えません

症状の判断や、料金の例外的な相談など、機械が答えるべきでない質問があります。このボットは分からないことを分からないと言い、電話とフォームに誘導して会話を終えます。間違った回答を返すことのほうが、お店にとって損失が大きいと考えているためです。実際に「保険は使えますか」と聞いてみてください。

HOW IT WORKS

この会話の裏側

入力された文章から「何を聞きたいのか」を判定し、お店の情報をまとめたナレッジから答えを返しています。判定できなかったときは、無理に答えず人へ渡します。

SCOPE

お引き受けできる範囲

お店ごとに聞かれることは違います。実際のご依頼では、いただいた資料と過去の問い合わせをもとに、そのお店専用の受け答えを設計します。

  • 受け答えの設計

    よくある質問の洗い出し、言い換えへの対応、答えてはいけないことの線引き。ここが品質の大半を決めます。

  • 予約の受付フロー

    希望日時・お名前・連絡先・ご相談内容を順に伺い、最後に内容を確認してから送信する形にします。

  • 既存サイトへの設置

    今あるホームページに、タグを1行足すだけで設置できます。サイトを作り直す必要はありません。

  • 問い合わせ内容の記録

    受けた予約や質問を、スプレッドシートやメールへ自動で残します。あとから見返せる形にします。

  • 公開後の調整

    実際に使い始めると、想定していなかった聞かれ方が必ず出ます。1か月は無償で調整します。

  • ホームページとセットの制作

    サイト自体からご依頼いただくこともできます。チャットボットを前提に導線を設計します。

このデモについて（正直にお伝えします）

このページのチャットボットは、お使いのブラウザの中だけで動いています。外部のサービスやAPIには接続していません。回答は、あらかじめ設計したナレッジ（お店の情報と受け答えの分岐）から返しています。無料で置き続けられ、いつでも同じ動きを確認していただけるようにするためです。

実際のご依頼では、Dify や ChatGPT の API に接続し、言い回しの揺れにより広く対応できる形で構築します。ただしその場合も、料金・営業時間・予約可否といった間違えてはいけない情報は、生成に任せず固定の回答から返す設計にします。お店の信用に関わる部分だからです。

「なごみ整体院」は制作サンプルのための架空の店舗で、住所・電話番号・料金はすべて架空のものです。
