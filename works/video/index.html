HOW IT WORKS

実際のコード

Remotion は、Reactで動画を書くための道具です。動画を「時間の関数」として書き、コマンドで MP4 に書き出します。下は上のプレビューと同じ構成の中心部分です。

// 4つの場面をつなぐ。1つの場面 = 決まった秒数のコンポーネント
export const Ad = ({ data }) => (
  <Series>
    <Series.Sequence durationInFrames={120}><Cover  title={data.title} sub={data.sub} /></Series.Sequence>
    <Series.Sequence durationInFrames={150}><Points points={data.points} /></Series.Sequence>
    <Series.Sequence durationInFrames={150}><Price  price={data.price} note={data.note} /></Series.Sequence>
    <Series.Sequence durationInFrames={180}><Outro  shop={data.shop} access={data.access} /></Series.Sequence>
  </Series>
);

// 文字が下から浮かび上がる動き。「今が何フレーム目か」から位置を決める
const Rise = ({ children, delay = 0 }) => {
  const frame = useCurrentFrame();
  const p = spring({ frame: frame - delay, fps: 30, config: { damping: 200 } });
  return <div style={{ opacity: p, transform: `translateY(${(1 - p) * 14}px)` }}>{children}</div>;
};

// スプレッドシートの1行 = 動画1本。行数ぶんまとめて書き出す
// npx remotion render Ad out/$SHOP.mp4 --props=./rows/$SHOP.json

  • 編集作業がありません

    タイムラインに素材を並べる工程がなくなります。10本作っても、増えるのはデータの行数だけです。

  • 直しが一瞬で全部に効きます

    「ロゴの位置を5px下げたい」を1か所直せば、全本に反映されます。書き出し直すだけです。

  • 体裁がぶれません

    人が並べないので、文字サイズや余白が本ごとに変わることがありません。

  • 差し替えを人に任せられます

    お店の方はスプレッドシートを編集するだけ。動画ソフトを触る必要がありません。

この作り方が向かないもの

1本だけの、凝った演出の動画には向きません。仕組みを組む時間のほうが長くなるためです。同じ体裁で数を作るときにだけ効きます。店舗ごとの広告、商品ごとの紹介、毎月の実績報告、求人票の動画版などが該当します。

このページについて

上のプレビューはブラウザ上で同じ構成を再現したもので、動画ファイルを再生しているわけではありません。動きと構成を確認していただくために用意しました。実際の納品は Remotion で書き出した MP4（1920×1080／30fps）です。

掲載しているコードは、この構成を Remotion で書いた場合の中心部分です。効果音やBGM、フォントの読み込みなどは省略しています。

「なごみ整体院」は制作サンプルのための架空の店舗で、金額・所在地はすべて架空です。
