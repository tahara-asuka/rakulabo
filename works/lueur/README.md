# Cafe Lueur — 架空の喫茶店 ランディングページ

制作: 田原明日翔 / ラクラボ
公開: https://tahara-asuka.github.io/lueur/

## 概要

北欧ミニマル（Japandi）を基調とした、架空の喫茶店のLPです。
架空案件として、コンセプト設計からコピーライティング、デザイン、実装まで一人で制作しました。

- 制作時間: 約6時間
- 使用技術: HTML / CSS / JavaScript（フレームワーク・ライブラリ不使用）
- ファイル数: 1（index.html 単体で完結）

## 設計のポイント

### 1. ライト／ダークテーマを「朝」と「夕方」として設計
店のストーリーにある「朝は差し込む朝日、夕方は真鍮のペンダントライト」を、
CSSカスタムプロパティで表現。閲覧環境のテーマ設定で、同じ店の朝と夜が切り替わります。
`prefers-color-scheme` に加え `data-theme` 属性にも対応（3状態すべてで破綻しない設計）。

### 2. Googleマップを使わず、SVGで地図を描き起こし
埋め込みマップは配色が固定されトーンが崩れるため、地図をSVGで自作しました。
区画・線路・川・徒歩ルートまで、すべてサイトのカラートークンで着色しているため、
ダークテーマでも配色が破綻しません。

### 3. 光と影をCSSで描画
ヒーローの光の帯は `skewY` + グラデーション + `mix-blend-mode: soft-light`。
写真に頼らず「光と影」というコンセプトを画面上で表現しています。

### 4. 構造が意味を持つように
順序に意味がある「道順」だけを連番（01, 02...）にし、
順位のない「3つのこだわり」には番号を振っていません。

## 実装した機能

- レスポンシブ対応（モバイル / タブレット / デスクトップ）
- 固定ヘッダー（ヒーローを抜けると背景が入る / IntersectionObserver）
- オーバーレイ型ナビゲーション（Escキー・背景クリックで閉じる / フォーカス制御あり）
- スクロール連動の表示アニメーション（`animation-timeline: view()`）
- `prefers-reduced-motion` 対応
- キーボード操作対応（`:focus-visible`）
- SEO / OGP メタタグ
- 画像の遅延読み込み（`loading="lazy"` / ヒーローのみ `fetchpriority="high"`）

## 写真の差し替え方

`index.html` 内の `https://images.unsplash.com/photo-...` を、
実際の店舗写真のパスに置き換えてください。
`img/` フォルダを作って配置する場合は `src="img/hero.jpg"` の形になります。
