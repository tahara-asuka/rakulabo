届いた問い合わせを、
そのまま台帳にする。

問い合わせメールから、お名前・連絡先・ご用件・希望日を抜き出して、スプレッドシートへ自動で追記する仕組みです。下のメール文面を編集して「実行」を押すと、その場で動きます。

実際に運用しているものと同じ判定ルールを、このページ上で再現しています。

いままで

  1. メールを開く
  2. 名前と電話番号をコピーする
  3. スプレッドシートに貼る

いま

  1. メールが届く
  2. 台帳に1行増えている

読み取れなかったメールは「要確認」に分けられ、人が見ます。

DESIGN

作るときに決めたこと

この手の自動化でいちばん危ないのは、失敗したことに気づかないまま動き続けることです。そこを最初に潰しました。

  • 読み取れないものは、混ぜない

    連絡先が見つからない、用件が判定できない。そうしたメールは台帳に入れず「要確認」へ分けます。中途半端な行が台帳に混ざるほうが、あとで困ります。

  • 二重登録を防ぐ

    処理したメールにはラベルを付け、次回はそれを除いて検索します。実行が重なっても同じ行が増えません。

  • 元のメールへ戻れるようにする

    各行にメールのIDを持たせ、台帳から元のメールを開けるようにします。要約だけでは判断できない場面が必ずあるためです。

  • 判定ルールは、お店ごとに書き換える

    用件の分け方も、拾う項目も、業種によって変わります。予約中心の店舗と、見積依頼が多い事務所では別物です。

この仕組みに向かない場合

問い合わせが1日1〜2件しかない場合は、自動化しても効果が実感しにくいです。手で転記しても数分で終わるためです。逆に、1日10件を超えたあたりから、転記そのものより「転記し忘れ」の損失が効いてきます。導入をお勧めするかどうかは、そこを伺ってから判断します。

CODE

実際の仕組み

Google Apps Script で動かします。5分おきに新着を確認し、条件に合うメールだけを処理します。Googleアカウントの中で完結するため、外部サービスに情報を渡しません。

/** 5分おきに実行。未処理の問い合わせメールを台帳へ追記する */
function collectInquiries() {
  const label   = GmailApp.getUserLabelByName('処理済み') || GmailApp.createLabel('処理済み');
  const sheet   = SpreadsheetApp.getActive().getSheetByName('問い合わせ台帳');
  const pending = SpreadsheetApp.getActive().getSheetByName('要確認');

  // 処理済みラベルが付いていないものだけを対象にする（二重登録の防止）
  const threads = GmailApp.search('label:inbox -label:処理済み subject:(お問い合わせ OR 予約)', 0, 30);

  threads.forEach(function (thread) {
    thread.getMessages().forEach(function (msg) {
      const parsed = parse(msg.getPlainBody(), msg.getFrom());

      if (parsed.missing.length) {
        // 読み取れなかった項目がある → 台帳には入れず、人が見る場所へ
        pending.appendRow([msg.getDate(), msg.getFrom(),
                           parsed.missing.join('／'), msg.getPlainBody().slice(0, 300)]);
      } else {
        sheet.appendRow([msg.getDate(), parsed.name, parsed.contact, parsed.topic,
                         parsed.date, parsed.summary, '未対応', msg.getId()]);
      }
    });
    thread.addLabel(label);
  });
}

/** 本文から必要な項目だけを抜き出す。拾えなければ missing に積む */
function parse(body, from) {
  const mail  = (body.match(/[\w.+-]+@[\w-]+\.[\w.-]+/) || [])[0];
  const tel   = (body.match(/0\d{1,4}[-\s]?\d{1,4}[-\s]?\d{3,4}/) || [])[0];
  const name  = (body.match(/(?:お名前|氏名)[\s:：]*(.+)/) || [])[1];
  const date  = (body.match(/(\d{1,2})\s*月\s*(\d{1,2})\s*日/) || [])[0];
  const topic = classify(body);

  const missing = [];
  if (!mail && !tel) missing.push('連絡先');
  if (!name)         missing.push('お名前');
  if (!topic)        missing.push('ご用件');

  return { name: name, contact: tel || mail, topic: topic,
           date: date || '指定なし', summary: summarize(body), missing: missing };
}

※ classify（用件の判定）と summarize（要約）は、お店ごとに内容が変わるため省略しています。上のデモでは、この2つを含む同じ処理をブラウザ上で再現しています。

SCOPE

同じ形で作れるもの

「決まった形で届くものを、決まった場所へ移す」作業は、だいたい同じ仕組みで自動化できます。

  • 予約サイトからの通知を台帳へ

    複数の予約サイトから届く通知を、1枚のシートにまとめます。媒体ごとに書式が違っても、それぞれに合わせて読み取ります。

  • 請求書メールを経理シートへ

    件名と本文から取引先・金額・支払期日を拾い、支払管理表に追記します。期日が近い行に色を付けることもできます。

  • フォーム回答を顧客台帳へ

    同じ方からの複数回の問い合わせを1行にまとめ、履歴として残します。

  • 日報・報告メールの集計

    毎日届く定型の報告から数字だけを抜き出し、月次の集計表を自動で作ります。

このページについて

上のデモはお使いのブラウザの中だけで動いています。メールを読み取ったり、どこかへ送信したりはしていません。入力した内容は保存されず、ページを閉じると消えます。

掲載しているコードは、実際に Google Apps Script で動かしている仕組みの中心部分です。Googleアカウントの中で完結するため、外部のサービスにメールの内容を渡さずに運用できます。

デモに出てくる会社名・氏名・連絡先は、すべて架空のものです。
